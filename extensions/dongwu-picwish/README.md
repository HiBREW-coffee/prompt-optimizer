# DONGWU · 佐糖生图助手 0.1.0

每位成员在自己的电脑浏览器安装一次。当前为内部试用版，适用于桌面 Edge / Chrome；没有手机扩展版。只在 DONGWU 与佐糖设计页面工作，不读取 Cookie、密码、API Key，也不调用生图 API。

## 安装

1. 从 DONGWU 右侧“佐糖生图”下载 ZIP，解压到一个固定文件夹。
2. Edge 打开 edge://extensions；Chrome 打开 chrome://extensions。打开“开发者模式”。
3. 点击“加载解压缩的扩展”，选择包含 manifest.json 的文件夹。
4. 确认浏览器要求的两个网站权限，再刷新 DONGWU。每个浏览器用户配置需要单独安装。
5. 升级时用新文件替换固定文件夹内容，并在扩展管理页点击重新加载；刷新 DONGWU 和助手窗口。此分发方式不自动更新。

## 使用

DONGWU 右侧点击“佐糖生图”，确认发送的提示词、需要保留和图片数量，再点“发送到佐糖”。最多五张原文件，按当前图1—图5顺序传送。后台逐块校验文件完整性；不把图片存入云端或扩展持久存储。

佐糖使用当前浏览器自己的登录账号和网页积分。助手只准备草稿，不会点击生成、购买、升级或修改账号。佐糖已有未发送草稿时会拒绝覆盖。请在佐糖核对图片、模型、模式、比例与分辨率，然后自行点击生成。

图片上传确认后才填写提示词，出现失败时请先检查佐糖已有图片，避免重复导入；不自动重试整份资料。所选模型无法接受全部图片时不会默默只传第一张。图片数量确认基于页面结构，佐糖改版后可能需要更新适配。

助手窗口可“全屏 / 还原”“收起”，从 DONGWU 再次打开。精简界面隐藏顶部导航、历史与账号区域，只作用于助手创建的专用窗口；点击“原站界面”恢复。正常打开的佐糖页面不修改。

生成、大图查看、后续改图和高清下载都由佐糖原页面完成。没有结果回传、截图保存或二次压缩。可选分辨率与实际画质由佐糖所选模型和账号权限决定。

当前页面新上传的原文件只在页面内存；刷新后需补传。旧云端参考图使用当时保存的版本，不可能自动恢复更早的高分辨率源文件。
