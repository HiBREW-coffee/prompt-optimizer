# 按当前意图提炼（2026-10-25）

修复场景风格需求被转成产品复刻的问题。旧实现的首次 `reference.extract` 固定拼入整图复刻模板，后续改写固定拼入完整图像迁移模板；这与“风格学习 / 灵感”规则冲突。润色和分析未使用相同的模式范围，且仅换图才会排除旧版本，改原文、保留项和模式仍可能继承旧产品细节。

现在所有操作共享当前意图协议。原文和明确保留项确定任务，参考图提供证据，模式决定处理方法，模板只提供专业检查维度。风格学习不默认复制图内产品、标牌与配件；复刻保持其原有精细程度；灵感允许任务范围内的变化。只学场景不因缺少产品结构或摄影参数而扣分。原文与保留项冲突必须明确指出，不能静默取消用户约束。原项目其他入口及模板不变。

除评估旧成果外，只有来源完整且与当前原文、保留项、图片及职责、模式、模板、已确认偏好均一致的版本才作为后续修改基线；其余按新输入重建，仍保留版本父子关系和旧历史。同输入的建议修改仍保留结构字段与细节保护。评估继续读取被评估版本，衡量它是否满足最新要求。

网页显示旧成果未按新输入生成的提示。未采用的润色建议不会更新原文或右侧成果；模式、保留项、图片变化也会让旧润色失效。新的润色恢复记录携带完整输入来源；缺失来源的旧记录仅供手动核对。保留栏显示会随请求发送的说明，提供单独清除按钮，不自动删除已有保留项。

网页提交 `expectedContext`，后台在请求准入和付费调用之前校验保存的当前输入，阻止跨页面改动把请求指向另一份需求。此字段可选以兼容正在使用的旧页面；更新网页后生效。没有新增自动模型调用、语义评分调用或重试，没有修改公司密钥或模型配置。

验证：完整 190 项网页测试通过；新增覆盖各调用的模式范围、输入改变后的旧主体隔离、同输入建议保真、旧成果评估、保留冲突、润色来源恢复、跨页面变更前置拒绝和界面提示。类型检查、模板同步、生产构建及产物检查通过。测试验证请求构建与控制流，不能保证模型不会发生语义偏差；真实图片结果仍需人工核对。
