# DONGWU 佐糖浏览器助手

## 范围

工作室右侧浮动按钮打开连接与发送面板，不重排原工作区。独立佐糖 popup 窗口可全屏/还原、最小化收起；从 DONGWU 再次展开。助手不点击生成、不调用供应商 API、不回传结果、不执行购买或账号操作。生成、继续改图、大图和下载仍使用佐糖原站。

窗口与传送实现依赖桌面 Chrome / Edge 扩展；每位成员、每台电脑、每个浏览器配置需安装一次。管理员安装不会自动覆盖其他成员。当前 ZIP 为内部手动分发，不是商店自动更新版。

## 构建与安装

`node scripts/build-picwish-extension.mjs` 生成 `supabase/.temp/dongwu-picwish/` 解压目录和网站下载包 `packages/web/team/public/downloads/dongwu-picwish-0.1.0.zip`。团队构建会先执行此步骤。下载包包含源码、README、AGPL 许可及现有头像图标；不包含环境文件、密钥或用户数据。

解压后，在 `edge://extensions` 或 `chrome://extensions` 开启开发者模式，加载包含 manifest.json 的目录。安装会为 DONGWU 与佐糖设计页授予读写页面权限，必须由用户审阅确认。安装后刷新工作室和助手窗口。新版本替换该目录文件并手动重新加载。

## 文件与权限

- DONGWU 发送已选中文成果或原始需求、需要保留及全部参考图，最多5张，顺序对应图1—图5。
- 新图原文件只保留在当前页面 Map 中，缩小的分析图与生图原文件分开。刷新后补传原文件。旧云端图使用当时保存版本，不能自动恢复更早源文件。
- 原文件每张≤10MB，按192KB分块传送，目标端校验字节长度和SHA-256。Chrome消息不直接携带大型File对象。
- 扩展仅保存专用窗口ID和尺寸到 storage.session；不持久化图片或提示词。传送内容只在内存中，结束、取消或页面卸载后释放。
- 不请求 cookies、debugger、webRequest、declarativeNetRequest、所有网站或跨域HTTP权限。没有读取会话令牌、密码、API Key，或移除 X-Frame-Options 的逻辑。
- DONGWU页面消息验证同窗口、来源、请求ID；后台只接受准确站点顶层页。图片传送绑定发起标签与传送ID，窗口控制只接受专用佐糖窗口。
- 佐糖普通标签不会被精简。专用窗口经后台确认后，才隐藏历史、顶部导航和账号区域；登录/安全/系统弹窗不隐藏，原站界面按钮可恢复。

## 导入与验收边界

依据佐糖当前公开页面结构适配 `#ai-chat-content-container textarea` 与图片粘贴上传流程。所有图完成上传并在编辑区确认数量后才填入提示词；不会自动执行付费生成。已有草稿、上传中用户新输入、校验失败、图数不足或模型超限均明确失败，不覆盖草稿、不自动整份重试。

DOM 图片数量回执不等于模型语义理解证明。真实安装后必须人工验收：1图/5图、切换模型后上限、原文件顺序与分辨率、登录弹窗、普通佐糖页不变、窗口全屏与收起、生成一次及官方原图下载。佐糖改版可能要求更新选择器。未完成真实验收前维持内部试用状态。

官方能力参考：Chrome content scripts / messaging / windows API。佐糖页面当前返回 SAMEORIGIN，因此没有采用 iframe 嵌入或反向代理登录态。
